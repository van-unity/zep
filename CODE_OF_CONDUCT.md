# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to the issue tracker, pull requests, discussions and any other space where the project is represented.

## In short

- Be respectful and assume good intent. Critique code and ideas, not people.
- No harassment, insults, sexualized language or imagery, or publishing of someone's private information.
- Accept that maintainers may edit, hide or remove comments, commits, issues and other contributions that break these rules, and may block people who repeatedly do so.

The full text of the Covenant, including its enforcement guidelines, is the authoritative version.

## Reporting

If someone's behavior in this project is unacceptable, contact the maintainer privately through the contact options on the [maintainer's GitHub profile](https://github.com/van-unity), or use GitHub's **Report content** option on the comment or issue concerned. Reports are handled confidentially, and you will get a reply acknowledging yours.

Please do not open a public issue to report a conduct problem.
